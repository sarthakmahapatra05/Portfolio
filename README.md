# 🏁 Getting Started

# 🔹 Clone Repository

```bash
git clone https://github.com/sarthakmahapatra05/Portfolio.git
```

---

# 🔹 Navigate To Project

```bash
cd Portfolio
```

---

# 🔹 Install Dependencies

```bash
npm install
```

---

# 🔹 Start Development Server

```bash
npm run dev
```

---

# 🔹 Open In Browser

```bash
http://localhost:5173
```
